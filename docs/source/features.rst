Features and Specifications
============================

The FLORATek 4 and FLORATek 4 Pro feature:

* Continuous pH, nutrient level, and temperature monitoring
* Proportional Smart Feed control for pH solutions and nutrients
* A new graphical user interface and menu system for improved ease of use
* Quick graphs that display historical pH and EC data for easily spotting trends
* Consumption tracking for all connected pH solutions and nutrients
* On-board memory for data logging w/ USB connectivity for downloading logs
* 4 integrated user-configurable dosing pumps
* Expandability to use 8 or 12 total dosing pumps
* Online access for remote monitoring, setup, and data logging
* Compatibility with future hardware and software updates

What's Included

Included with every FLORATek 4 and FLORATek 4 Pro System:

* Control with 4 integrated dosing pumps
* Tubing

* EC/Temperature Probe
