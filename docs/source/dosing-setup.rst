Dosing Setup
============

Once your FLORATek setup menus are configured, it is time to input information on your desired nutrient dosing. Your control will use this information to calculate how much of each nutrient to add. You can find this information on the desired stage/week of your nutrient's feedchart.

The Dosing Setup menu will display the current growday for your convenience. This can be helpful when referencing the feedchart for your nutrient system.

All nutrient setpoints are in mL/gallon. Note that the FLORATek 4 does not use the nutrient setpoints directly when dosing - it examines all of your nutrient setpoints to determine the desired nutrient ratio, then uses that ratio to accurately dose to your EC Setpoint.




Menu Settings
-------------

Current Growday
---------------
Displays the current growday. To set or reset the current growday, see "Set Growday" below.

pH Setpoint
-----------
Displays and adjusts the current pH setpoint.

EC Setpoint
-----------
Displays and adjusts the current EC setpoint. To change your EC units, see "EC Units" in System Setup.

EC Base
-------
Displays and adjusts the current EC base. See the :doc:`ec-control` section in the manual for more information. When the EC base is set greater than 0, an asterisk (*) will display on the home screen alongside the EC setpoint.

Nutrient Setpoints
------------------
Displays and adjusts the current nutrient setpoints in mL/gal. The nutrient setpoints are used to calculate the proper nutrient ratio which the control will use to reach the EC setpoint. This information can be found on the feedchart for your particular nutrients.

Available settings: Nutrient A, Nutrient B, and additional nutrients as configured.

Set Growday
-----------
Use to adjust the current growday.

Reset to Day 1
--------------
Use to set the current growday to 1.

Reset Current Dose
------------------
When the control is paused, this function can be used to reset the current dose calculations.
